# HD-002 — Website fails to load (simulation)

**Priority:** Medium | **Impact:** One user | **Status:** Escalated in scenario

**Report:** Browser cannot open one work site, while other sites load.

**Triage:** Confirm exact URL and error. Check whether other users are affected. Compare DNS resolution with a known public domain and test HTTPS connectivity. Never paste credentials or internal URLs into a public ticket.

**Scenario findings:** General connectivity succeeds, but the work hostname does not resolve on the approved network.

**Action:** Record the sanitized error and time. Escalate to the network/DNS team with affected scope and checks performed. Do not change managed DNS settings without authorization.

**Validation:** Network team confirms a corrected DNS record; user confirms site loads. Close after user confirmation.
