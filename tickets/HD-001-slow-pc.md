# HD-001 — Slow Windows PC (simulation)

**Priority:** Low | **Impact:** One user | **Status:** Resolved in scenario

**Report:** User says the PC is slow when opening several browser tabs.

**Triage:** Confirm when it began, whether other apps are affected, and whether the device recently restarted. Check free space and memory; inspect startup applications with the user. Avoid deleting files without the owner's approval.

**Scenario findings:** System drive has less than 10% free space. Memory usage rises while many tabs are open.

**Action:** Guide the user through reviewing large downloads and unused apps. Close unused tabs and restart. Do not remove user files on their behalf.

**Validation:** User confirms browser and apps respond normally after restart. Advise follow-up if low disk space returns.
